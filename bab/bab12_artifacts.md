# Bab 12 – Manual Pendaftaran Akaun GitHub & GitHub Desktop

Untuk menjadikan sistem anda boleh dibuka oleh sesiapa sahaja di internet melalui pautan web awam (*Live Web Link*), kita akan menggunakan perkhidmatan percuma **GitHub** dan alatan visual **GitHub Desktop**.

---

## 12.1 Mengapa Memilih GitHub & GitHub Desktop?
* **GitHub.com**: Portal simpanan fail perisian percuma yang menyediakan kemudahan pelancaran pautan web awam (*GitHub Pages*).
* **GitHub Desktop**: Aplikasi perisian visual (*GUI app*) yang membolehkan anda memuat naik fail projek dari komputer ke GitHub **tanpa menaip sebarang perintah arahan terminal**.

### 📍 Langkah 12.1: Cipta Akaun GitHub (Percuma)
1. Buka pelayar web dan layari: `https://github.com/signup`
2. Masukkan e-mel anda, cipta kata laluan (*password*), dan nama pengguna (*username*).
3. Melengkapkan pengesahan e-mel yang dihantar ke peti masuk anda.

### 📍 Langkah 12.2: Muat Turun GitHub Desktop
1. Layari: `https://desktop.github.com/`
2. Klik butang **Download for Windows** (atau Mac).
3. Pasang aplikasi **GitHub Desktop** di komputer anda.

### 📍 Langkah 12.3: Log Masuk di GitHub Desktop
1. Buka aplikasi **GitHub Desktop**.
2. Klik butang **Sign in to GitHub.com**.
3. Pelayar web akan mengesahkan log masuk akaun anda secara automatik.
