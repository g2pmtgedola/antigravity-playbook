# Bab 7 – Koleksi Master Prompt Siap Guna (5 Jenis Utama)

Dalam bab ini, anda disediakan **5 Koleksi Master Prompt Siap Guna** yang telah direkabentuk khas mengikut 5 kategori utama. Anda hanya perlu **Salin (Copy)** teks di dalam kotak dan **Tampal (Paste)** terus ke dalam Google Antigravity!

---

## 📋 5 Koleksi Master Prompt

### 1. Master Prompt: Membina Sistem (Kehadiran & Data Staf)
```text
Bina Sistem Pengurusan Kehadiran Staf Harian di fail index.html menggunakan Tailwind CSS CDN (Mod Gelap).

Keperluan Utama:
1. Borang pendaftaran: Nama Staf, Tarikh, Masa Clock-in, dan Pilihan Status (Hadir / Cuti / Sakit).
2. Butang "Simpan Kehadiran".
3. Jadual senarai kehadiran staf di bawah borang yang menyimpan data secara kekal di dalam localStorage.
4. Butang "Padam Rekod" pada setiap baris jadual untuk memadam rekod tertentu.
5. Petak carian (Search Bar) untuk menapis nama staf secara automatik.
```

---

### 2. Master Prompt: Membina Dashboard (Admin Jualan & Carta Visual)
```text
Bina Admin Dashboard Pengurusan Jualan Moden di fail index.html menggunakan Tailwind CSS CDN (Mod Gelap).

Keperluan Utama:
1. 4 Kad Statistik KPI: Total Jualan (RM50,000), Jumlah Pesanan (1,200), Pelanggan Baharu (850), dan Kadar Kejayaan (98.5%).
2. Carta Trend Jualan Bulanan interaktif menggunakan skrip Chart.js CDN.
3. Jadual Transaksi Terkini mengandungi ID Pesanan, Nama Pelanggan, Jumlah (RM), dan Badge Status (Hijau = Kejayaan, Kuning = Menunggu, Merah = Gagal).
```

---

### 3. Master Prompt: Membina Laman Web (Landing Page Perniagaan)
```text
Bina Landing Page moden perniagaan "Katering Enak Rasa" di fail index.html menggunakan Tailwind CSS CDN.

Keperluan Utama:
1. Header & Navigation Bar dengan logo "Katering Enak Rasa" dan butang CTA "Hubungi Kami".
2. Hero Section: Tajuk gradient menawan, penerangan ringkas, dan butang tempahan.
3. 3 Kad Pakej Hidangan: Pakej Hemat (RM15/pax), Pakej Selera (RM25/pax), Pakej VIP (RM45/pax).
4. Borang Pertanyaan Tempahan: Nama, Nombor WhatsApp, Tarikh Majlis, dan Jumlah Tetamu.
5. Footer lengkap dengan lokasi pejabat dan pautan media sosial.
```

---

### 4. Master Prompt: Membina Platform Game (Arcade Game HTML5)
```text
Bina Platform Permainan Mini (Mini-Game Arcade) di fail index.html menggunakan Tailwind CSS CDN.

Keperluan Utama:
1. Tajuk Utama: "Pusat Permainan Arcade Interaktif".
2. Game 1: Permainan Tic-Tac-Toe (X dan O) 2 pemain yang boleh dimainkan secara interaktif di skrin.
3. Game 2: Permainan Kuiz Pengetahuan Umum dengan 5 soalan berbilang pilihan dan paparan markah akhir.
4. Paparan Skor Tertinggi (High Score Leaderboard) yang disimpan di dalam localStorage.
```

---

### 5. Master Prompt: Membina Playbook (Laman Web Dokumentasi Tabbed)
```text
Bina Laman Web Playbook Interaktif Tabbed di fail index.html menggunakan Tailwind CSS CDN.

Keperluan Utama:
1. Header atas dengan tajuk "Playbook Panduan Pengguna".
2. Bar Navigasi Tab Horizontal di atas untuk bertukar bab (Bab 1, Bab 2, Bab 3, Bab 4, Bab 5).
3. Kandungan setiap bab dipaparkan mengikut tab yang dipilih secara serta-merta tanpa refresh halaman.
4. Butang "Bab Sebelumnya" dan "Bab Seterusnya" di bahagian bawah skrin untuk pembacaan lancar.
```
